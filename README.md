# MDD 분석기

**👉 사이트 바로가기: https://pcw7.github.io/mdd-analyzer/**

종목의 고점 대비 하락률(MDD)과 하락률 분포를 보고 저점매수 구간을 찾는 웹사이트예요.
GitHub Pages에 올려서 브라우저로 볼 수 있고, 내 PC에서 실행하면 아무 종목이나 바로 조회할 수 있어요.

> 개인 참고용 비상업 도구예요. 투자 권유가 아니며, 과거의 하락 패턴이 앞으로도 반복된다는 보장은 없어요.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `site/` | 웹사이트 (GitHub Pages에 그대로 올라가는 폴더) |
| `site/mdd.js` | MDD·분포·하락장 계산 로직 |
| `site/data/` | 가격 데이터 (자동 생성, 저장소에는 올리지 않음) |
| `tickers.json` | 사이트에 넣을 종목 목록 |
| `scripts/build_data.py` | `tickers.json`의 종목 데이터를 야후 파이낸스에서 받아 `site/data/`에 저장 |
| `.github/workflows/deploy.yml` | 데이터 생성 → GitHub Pages 배포 (push할 때, 그리고 매일 아침 7시) |
| `app.py` | 내 PC용 서버 (같은 화면에서 아무 종목이나 조회) |

## GitHub Pages로 배포하기

1. GitHub에서 저장소를 만들고 이 폴더를 `main` 브랜치에 push해요.
2. 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔요.
3. **Actions** 탭에서 "사이트 배포"가 끝나면 `https://<아이디>.github.io/<저장소 이름>/` 에서 볼 수 있어요.
   - 처음 한 번은 Actions 탭에서 "사이트 배포" → **Run workflow**로 직접 실행해도 돼요.

이후에는 화~토 한국시간 오전 7시에 데이터가 자동으로 갱신돼요.
공개 저장소는 60일 동안 커밋이 없으면 예약 실행이 멈추니, 그때는 Actions 탭에서 다시 켜 주세요.

## 종목 바꾸기

`tickers.json`을 고쳐서 push하면 돼요. `label`은 화면에 보일 이름이에요(생략 가능).

```json
[
  { "code": "QQQ" },
  { "code": "005930", "label": "삼성전자" },
  { "code": "BTCUSD", "label": "비트코인" }
]
```

| 입력 | 예시 |
|---|---|
| 미국 주식·ETF | `QQQ`, `SPY`, `AAPL` |
| 국내 종목 (6자리) | `005930`, `247540` (코스피 → 코스닥 순으로 찾아요) |
| 비트코인·금 | `BTCUSD`, `GCW00` (구글 시트 코드도 돼요) |
| 지수 | `KOSPI`, `KOSDAQ`, `SPX`, `^NDX` |
| 그 밖의 야후 코드 | `7203.T`, `BTC-USD`, `GC=F` |

## 내 PC에서 실행하기

**아무 종목이나 조회 (로컬 서버)**: `run.bat`을 더블클릭하면 돼요. 처음에만 패키지를 설치하고, 브라우저에서 http://127.0.0.1:8050 이 열려요.

**배포될 사이트 그대로 미리보기**:

```
.venv\Scripts\python scripts\build_data.py
.venv\Scripts\python -m http.server 8000 -d site
```

그다음 http://127.0.0.1:8000 을 열면 돼요.

## 화면에 나오는 숫자

- **고점 대비 현재**: 조회 기간의 최고 종가 대비 지금 종가가 몇 % 아래인지
- **최대 하락 (MDD)**: 조회 기간 중 가장 깊었던 고점 대비 하락률
- **평균 하락률**: 매일의 고점 대비 하락률을 평균 낸 값
- **회복률**: 하락폭이 그 구간보다 얕았던 날의 비율. 예를 들어 -70% 행의 89.7%는 전체 거래일 중 89.7%가 -70%보다 덜 빠져 있었다는 뜻이에요
- **저점매수 구간**: 회복률이 기준(ETF·지수 80%, 개별종목 90%)을 처음 넘는 구간
- **매수 기준가**: 과거 최고가 × (1 + 기준 %)

## 데이터와 이용 조건

- 야후 파이낸스(yfinance)의 일별 종가를 써요. 기본은 액면분할만 반영한 종가이고, "배당 반영"을 켜면 수정주가를 써요.
- 원화 기준은 같은 날의 환율(USD/KRW 등)로 환산하며, 환율 데이터는 2003년 12월부터 있어요.
- yfinance는 야후와 관계없는 오픈소스 도구이고, 야후 데이터는 개인 용도로만 쓰도록 되어 있어요.
  그래서 가격 데이터는 저장소에 커밋하지 않고 배포할 때만 만들며, 광고나 유료 기능은 넣지 않아요.
